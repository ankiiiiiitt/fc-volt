# Comparison background assets

Four original images generated with the built-in image_gen tool for FC VOLT. No stock-photo service, remote image host, API key or runtime generation is used. JPEG copies are web-optimized at quality 88, retaining the generated dimensions (971 × 1619). Twelve presets reuse these four images with different translucent color overlays; they are not twelve separate original scenes. Original PNGs are retained in Codex's generated_images directory.

Final asset files:

- `champions-night.jpg`
- `neon-tunnel.jpg`
- `golden-arena.jpg`
- `cosmic-stadium.jpg`
