# Reference UI assets

`level30.png` and `rank-orange.png` are small deterministic crops from the max-card reference supplied by the user (`FC Mobile Gabriel Player Card Stats.png`, 1862×845). They are used only for the orange training badge and rank indicators. They were not generated with AI in this implementation. The surrounding screenshot, player face, card artwork, stars and PlayStyles are never copied from that max-card reference.

The automatic engine uses source screenshot pixels for all protected content and copies active skill-icon diamonds from the uploaded RenderZ image. Full user screenshots are not included in the repository or deployed assets. These football-game UI graphics remain subject to their respective owners' rights; FC VOLT exports are fan-made previews.
